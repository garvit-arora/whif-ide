Before you
find your flow.

Do I need to download Wispr IDE and Wispr Flow?

Yes. Download and install both Wispr IDE and the official Wispr Flow desktop app to use the voice-first workflow. Keep Wispr Flow running and match its shortcut in the IDE. This website is the product guide and draft space, not a replacement for either desktop app.

Download Wispr IDE ↗Download Wispr Flow ↗
Can I use my existing agent account?

Wispr IDE checks installed Codex and Claude Code CLIs and uses their own sign-in flows. Provider access, model availability, usage limits, and billing still apply.

Does automatic dictation work everywhere?

Verified automatic shortcut observation is implemented for Windows. Other platforms can use manual dictation and submission. The Flow app must be running and its shortcut must match the IDE configuration.

What happens when I stop an agent?

The IDE requests interruption of its active agent session. Stopping cannot undo file edits, commands, or other actions that have already completed. Review changes before continuing.

Where will downloads appear?

Published installers and release notes will appear in the release cabinet once real artifacts are available. The release cabinet is connected to garvit-arora/whif-ide on GitHub and loads its published releases. Download Wispr Flow separately from its official website.
